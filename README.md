
# QSpiders Training Batch Performance Dashboard

An interactive dashboard to track training batches, student enrollments, course progress, and schedules at **QSpiders, Punjagutta, Hyderabad**.

### [View Live Dashboard](https://docs.google.com/spreadsheets/d/e/2PACX-1vS1tGdnPDJOzR4AT8CPMx-eA70mPx6gs0tyKzsch_fmZJxyJwa2FMNCdmzMbXvNn0d9glrFWFc82_n4/pubhtml?gid=1649173159&single=true)

## Overview

The dashboard provides a clear view of training activities across **Excel, SQL, and Power BI** courses.

## Key Features

- Track completed and ongoing batches.
- Monitor student enrollments and batch sizes.
- Analyze course performance and completion rates.
- View training schedules and monthly trends.
- Filter data by subject, status, candidate type, and month.
