# QSpiders Training Batch Performance Dashboard

An interactive training operations dashboard for **QSpiders, Punjagutta (Hyderabad)**, bringing batch schedules, student enrollment, completion status, and course-level performance into one view.

> **Live view:** Open the link above for the currently published interactive dashboard. The GitHub README is a static project overview; its figures do not automatically synchronize with the dashboard.

## Overview

The dashboard provides a consolidated view of training activity across **Excel, SQL, and Power BI** courses. It helps track active and completed batches, enrollment volume, training timelines, and course performance.

## Key features

- **Executive overview:** Total batches, enrollment, completed and ongoing batches, average batch size, and training days.
- **Course analytics:** Student enrollment, batch distribution, and completion rates by subject.
- **Batch monitoring:** Active batch schedules, start dates, timings, and student counts.
- **Performance trends:** Monthly batch activity, capacity analysis, and training timeline visualization.
- **Interactive exploration:** Filter by subject, status, candidate type, or month; inspect the batch grid and insights.
